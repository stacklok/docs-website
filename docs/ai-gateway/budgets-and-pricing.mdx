A _budget_ caps model spend in USD for a directory user or group. Before the AI
Gateway calls a provider, it asks the budgets service in the Enterprise Manager
to admit the request. After the response, it reports the provider's usage so the
service can charge it.

Use [Budgets](manage-budgets.mdx) in the console for routine administration. Use
the REST API for automation, bulk import, and pricing. To connect the gateway to
the budgets service, see [Budget enforcement](budget-enforcement.mdx).

:::danger[Cover every caller before you turn enforcement on]

Budget enforcement refuses every caller without an applicable budget. Cover
every caller before you connect a gateway that serves traffic.

:::

## When a budget runs out

The gateway refuses the caller's requests until the budget has capacity again.
Check the caller in the console to tell an exhausted budget apart from missing
coverage.

Access resumes when the calendar period resets. To restore access immediately,
raise the limit. The change applies on the next request and preserves the usage
counter.
