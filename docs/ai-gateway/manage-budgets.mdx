Use the **Budgets** screen to set the organization default and limits for users
and groups.

Budget enforcement denies model requests from callers without an applicable
budget. Configure an organization default before you connect the gateway to the
budgets service. See [Budgets and pricing](budgets-and-pricing.mdx) for the API,
model pricing, and what callers see when a budget runs out.

## Set the organization default

On the **User Budgets** tab, select **Defaults**, then set the budget amount and
period applied to users without a custom budget.

## Group budgets

The **Group Budgets** tab lists each group's **Priority**, **Period**,
**Budget**, **Used**, and **Utilization**. Select **Create Group Budget**, then
choose a group, daily, monthly, or yearly period, and limit. Budget periods
align with the calendar.

To change a group budget's limit or period, or remove it, use **Edit budget** or
**Delete budget** in the row's actions menu.

Priority, called `precedence` in the API, orders group budgets for charging. To
reorder them, select **Edit Budgets**, drag the rows into the order you want,
and select **Done**. See
[Which budget gets charged](budgets-and-pricing.mdx#which-budget-gets-charged)
for the full charge order.

## User budgets

The **User Budgets** tab lists each user's **Budget source**, **Period**, and
**Limit**. **Default** identifies the organization default, and **Custom**
identifies a custom budget for that user.

Each row's actions menu changes the user's budget:

- **Set a custom budget** gives a user on the default their own limit and
  period.
- **Edit custom budget** changes an existing custom budget.
- **Use default** discards the custom budget and returns the user to the
  organization default, after you confirm. When no organization default exists,
  the action is **Remove personal budget**, and the user has no user budget
  afterward.

Changes take effect on the next request and preserve current-period usage. Raise
an exhausted user's limit to restore access before the period resets.

### How user and group budgets combine

A custom budget caps a user's spend only when none of their groups has a group
budget with capacity, because group budgets take over when the user's own budget
runs out. Before you set a small custom budget to limit one user, check the
budgets of the groups they belong to. See
[Which budget gets charged](budgets-and-pricing.mdx#which-budget-gets-charged).

## Monitor spend

The **Organization** screen, under **Cost Management**, is the overview of AI
spend across your organization. Use it to see where spend is going and who is
near or over budget.

The **Total spend** card charts daily spend through the current day, covering
the usage history the console retains, four weeks by default. It also compares
spend over the last 7 days with the 7 days before.

Below the chart, the usage table's **Groups** and **Users** tabs list each
group's or user's spend, budget, and utilization. Search by name, or filter by
utilization: **All**, **Under 80%**, **80–100%**, or **Over 100%**. The
**Users** tab doesn't list spend charged to the organization default budget, so
it's empty when every user is on the default.

For finance reports and external dashboards, use the
[spend API](budgets-and-pricing.mdx#monitor-spend).
