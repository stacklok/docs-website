In this quickstart, you register the public DeepWiki MCP server as a connector,
grant it to a directory group, call one of its tools from Claude Code through
the Connector Gateway, and see the call on the **Tool Usage** screen. You act as
both the administrator and the user.

## Prerequisites

- A Stacklok Enterprise deployment with the Connector Gateway enabled, as
  described in
  [Configure the Connector Gateway](../platform/enterprise-platform/configure-connector-gateway.mdx).
- Tool call recording turned on, as described in
  [Record tool calls](./tool-usage.mdx#record-tool-calls). Without it, the last
  step shows no data.
- Outbound internet access from the Enterprise Manager and Connector Gateway
  pods, so they can reach `https://mcp.deepwiki.com`.
- A console account with administrator access that also belongs to a directory
  group. See
  [Users and groups](../platform/enterprise-directory/users-and-groups.mdx).
- [Claude Code](https://docs.claude.com/en/docs/claude-code/overview) installed
  on your workstation.

## Step 1: Register the connector

1. In the console's Administration experience, open **Connectors** and select
   **Add connector**.
2. Choose **Configure manually** and fill in the form:
   - **Name**: `DeepWiki`
   - **Backend auth**: **None**
   - **Endpoint**: `https://mcp.deepwiki.com/mcp`
   - **Transport**: **Streamable HTTP**
3. Select **Add connector**.

The Enterprise Manager verifies the endpoint when you add the connector. The
console confirms "DeepWiki added to Connectors", and the connector shows
**Verified** in the list.

## Step 2: Grant access to your group

1. Open the **DeepWiki** connector. The **Access** tab opens by default and
   shows no groups under **Groups with access**.
2. Select **Add groups**, choose a group you belong to, and select **Grant
   access**.

The group now appears under **Groups with access**, and its members can connect
to DeepWiki.

## Step 3: Connect to the connector as a user

1. Open the account menu and choose **User** under **Experience**.
2. Select **Connectors** under **Gateways**. DeepWiki appears under
   **Available**.
3. Select **Connect** on DeepWiki.

The console confirms "Connected to DeepWiki", and the connector moves to
**Enabled** with a **Connected** badge.

## Step 4: Connect Claude Code

1. On the same **Connectors** page, select the **Clients** tab and copy the
   endpoint URL from **Manual setup**.
2. Add the gateway to Claude Code, replacing `<ENDPOINT_URL>` with the URL you
   copied:

   ```bash
   claude mcp add --transport http connector-gateway <ENDPOINT_URL>
   ```

3. Start Claude Code with `claude`, run `/mcp`, select `connector-gateway`, and
   choose to authenticate. Complete the sign-in with your corporate identity
   provider in the browser window that opens.

After you sign in, `/mcp` shows `connector-gateway` as connected. Its tools
include DeepWiki's `ask_question`, prefixed with the connector's name and an ID,
such as `DeepWiki_<ID>_ask_question`.

## Step 5: Call a tool

Ask Claude Code a question that uses DeepWiki:

```text
Use DeepWiki to explain what the modelcontextprotocol/servers repository contains.
```

Approve the tool call when Claude Code asks. Claude Code calls `ask_question`
through the Connector Gateway and answers from DeepWiki's response.

## Step 6: See the call in Tool Usage

1. Switch back to the Administration experience and open **Tool Usage** under
   **Connectors**.
2. With **Last 24h** selected, find DeepWiki on the **By connector** tab. Its
   call count includes your call.
3. Select **By tool** and find `ask_question`, the DeepWiki tool you called.

The gateway delivers recorded calls within a few seconds. If the tiles are still
empty, reload the page.

## What you accomplished

You registered a connector, granted it to a directory group, connected to it as
a user, called its tool from an MCP client through one gateway endpoint, and
confirmed the call in the console. The same flow applies to any connector; most
production connectors add backend authentication.

## Troubleshooting

<details>
<summary>The connector shows Broken after you add it</summary>

The Enterprise Manager couldn't reach `https://mcp.deepwiki.com`. Check the
Enterprise Manager pod's outbound network access, then open the connector's
**Configuration** tab and select **Save and verify**. See
[A connector shows Broken](./connectors.mdx#troubleshooting).

</details>

<details>
<summary>Claude Code lists no DeepWiki tools</summary>

In the user experience, open **Connectors** under **Gateways**. On the **Tools**
tab, check that DeepWiki shows **Connected**. Also check that your account
belongs to the group you granted in step 2. Then restart Claude Code so it lists
the gateway's tools again.

</details>
