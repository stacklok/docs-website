The platform chart deploys three backend REST APIs for administration and
automation. The console uses these APIs.

All three use cluster-internal Services. Each reference identifies the Service,
port, and base URL to use, with a port-forward example for local access.
[Deploy the platform](./deployment.mdx#6-expose-the-platform-endpoints) covers
exposing the Enterprise Manager. The gateway references describe their separate
API routing targets.

## Enterprise Manager

[Enterprise Manager API reference](./enterprise-manager-api.mdx) covers users,
groups, connectors, managed secrets, virtual API keys, budgets, and signed
Stacklok CLI configuration.

## Connector Gateway

[Connector Gateway API reference](../../connector-gateway/api-reference.mdx)
covers each connector's upstream connection status and tools, and the flow that
connects a connector on the user's behalf. Connector administration and users'
enable and disable operations use the
[Enterprise Manager API](./enterprise-manager-api.mdx).

## AI Gateway management

The legacy AI Gateway has a management API for caller identity and gateway-wide
model and MCP server catalogs. See the
[management API reference](../../ai-gateway/legacy/api-reference.mdx). The
current AI Gateway serves its client endpoints only, listed in the
[endpoints reference](../../ai-gateway/endpoints-reference.mdx).

## Registry Server

The Registry Server is also deployed by this chart. Its API is shared with the
open source build. See the
[Registry Server API reference](../../toolhive/reference/registry-api.mdx).
