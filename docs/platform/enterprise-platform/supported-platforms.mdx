This page lists the Kubernetes platforms that Stacklok validates for the
Stacklok Enterprise platform, and the commercial support that applies to them.
Check it before you [deploy the platform](./deployment.mdx).

## Kubernetes version

The platform requires Kubernetes 1.30 or later. The umbrella chart sets
`kubeVersion: ">=1.30.0-0"`, so Helm refuses to install on an older cluster.

## Validated platforms

Stacklok runs a recurring end-to-end test on each validated platform. A version
appears in this table after that test passes on it.

| Platform                     | Validated versions                            | Recurring test          |
| ---------------------------- | --------------------------------------------- | ----------------------- |
| SUSE Rancher Prime with RKE2 | Rancher Prime v2.15.3 and RKE2 v1.36.5+rke2r1 | Weekly                  |
| Amazon EKS                   | EKS 1.36                                      | Every release candidate |

### SUSE Rancher Prime and RKE2

Stacklok supports the platform on RKE2 v1.36 clusters that SUSE Rancher Prime
v2.15 manages. Stacklok validated this configuration:

| Component                    | Version or setting                                                       |
| ---------------------------- | ------------------------------------------------------------------------ |
| SUSE Rancher Prime           | v2.15.3                                                                  |
| RKE2                         | v1.36.5+rke2r1, with the CIS profile                                     |
| Pod Security Admission       | `rancher-restricted` as the cluster default, with no namespace exemption |
| Node operating system        | SUSE Linux Enterprise Server (SLES) 16.0                                 |
| Storage                      | Longhorn 1.12.1                                                          |
| PostgreSQL                   | PostgreSQL 17 on CloudNativePG                                           |
| Stacklok Enterprise platform | 0.27.0, installed as a Rancher app from the Stacklok OCI registry        |

The validation covers the ToolHive Operator, the Registry Server, the console,
Enterprise Manager, the Replicated SDK, and the MCP server pods that the
operator creates. Each runs under `rancher-restricted` with no Pod Security
violation.

The weekly test installs the platform, runs the preflight checks, reconciles an
`MCPServer` as a smoke test, audits Pod Security, and collects a support bundle.
Stacklok adds each newly validated Rancher Prime and RKE2 version to this page.

The AI Gateway, the Connector Gateway, and the Workspace run on RKE2 without a
recurring test today. Contact Stacklok before you enable them on RKE2 in
production.

Keep these RKE2 defaults in mind when you write your values file:

- Add your cluster's pod and service CIDRs to
  `enterprise-manager.directory.connectorVerification.allowedPrivateRanges`.
  RKE2 defaults to `10.42.0.0/16` for pods and `10.43.0.0/16` for services.
  Rancher shows the values in use under **Cluster Configuration** >
  **Networking** as **Cluster CIDR** and **Service CIDR**. See
  [RKE2 cluster configuration](https://ranchermanager.docs.rancher.com/reference-guides/cluster-configuration/rancher-server-configuration/rke2-cluster-configuration).
- The RKE2 service account issuer is
  `https://kubernetes.default.svc.cluster.local`. Set it in
  `enterprise-manager.grpc.callerAuth.clusterOidcIssuer`. Enterprise Manager
  fetches the issuer keys from the Kubernetes API server on port 6443.
- RKE2 ships Traefik as the default IngressClass, `traefik`. The chart renders
  no Ingress, so you create one for the console and Enterprise Manager.
- Rancher Apps stores the chart package in a Kubernetes Secret, which holds at
  most 1 MiB. Every platform release from 0.26.0 fits within that limit.

### Amazon EKS

Stacklok tests every release candidate on Amazon EKS 1.36 before it promotes the
release to the Stable channel. The functional test suite installs the platform
and runs end-to-end tests against it.

## Other Kubernetes distributions

Other conformant distributions at Kubernetes 1.30 or later can run the platform
without a recurring Stacklok test. This includes Red Hat OpenShift Container
Platform. Before you install on one of them in production, contact Stacklok to
confirm the distribution.

## Commercial support

Stacklok provides commercial support for the platform on each validated platform
on this page, including SUSE Rancher Prime v2.15 with RKE2 v1.36.

The [Stacklok Platform Terms](https://stacklok.com/platform-terms/) govern that
support. Your order form names your support tier, and the tier sets the response
times. Support covers the supported platform versions: the latest release and
the two releases before it. See
[Enterprise support](../../toolhive/support.mdx#enterprise-support) for how to
reach the support team.

SUSE supports Rancher Prime, RKE2, and SLES under your SUSE subscription.
Stacklok supports the Stacklok Enterprise platform that runs on them.
