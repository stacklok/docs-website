This page lists the Kubernetes platforms that Stacklok validates for the
Stacklok Enterprise platform, and the commercial support that applies to them.
Check it before you [deploy the platform](./deployment.mdx).

## Kubernetes version

The platform requires Kubernetes 1.30 or later. The umbrella chart sets
`kubeVersion: ">=1.30.0-0"`, so Helm refuses to install on an older cluster.

## Validated platforms

Stacklok tests each platform in this table for every release candidate. A
release reaches the Stable channel only after the end-to-end test passes on
every platform.

| Platform                       | Version                             | Tested patch versions                      | Platform release | Validated  | Status    |
| ------------------------------ | ----------------------------------- | ------------------------------------------ | ---------------- | ---------- | --------- |
| Azure Kubernetes Service (AKS) | v1.36                               | Kubernetes v1.36.5                         | 0.27.0           | 2026-11-17 | Validated |
| Amazon EKS                     | v1.36                               | Platform version eks.17                    | 0.28.0           | 2026-11-18 | Supported |
| SUSE Rancher Prime with RKE2   | RKE2 v1.36 with Rancher Prime v2.15 | RKE2 v1.36.5+rke2r1, Rancher Prime v2.15.3 | 0.27.0           | 2026-11-17 | Supported |

The table orders the platforms AKS, EKS, then RKE2, with the newest version of
each platform first. The release candidate test runs on the newest version of
each platform. The **Status** column uses these values:

- **Supported:** the version has commercial support. Support includes later
  patch releases of the same minor versions.
- **Validated:** Stacklok tests the platform on this version. Contact Stacklok
  before you run it in production.
- **End of life:** the platform vendor ended support for this version.

When a platform vendor releases a new minor version, Stacklok validates it and
adds a row above the older versions of that platform.

## Other Kubernetes distributions

Other conformant distributions at Kubernetes 1.30 or later can run the platform,
outside the Stacklok release candidate test. This includes Red Hat OpenShift
Container Platform. Before you install on one of them in production, contact
Stacklok to confirm the distribution.

## Commercial support

Stacklok provides commercial support for the platform on each version marked
**Supported** in the [validated platforms](#validated-platforms) table.

The [Stacklok Platform Terms](https://stacklok.com/platform-terms/) govern that
support. Your order form names your support tier, and the tier sets the response
times. Support covers the supported platform versions: the latest release and
the two releases before it. See
[Enterprise support](../../toolhive/support.mdx#enterprise-support) for how to
reach the support team.

SUSE supports Rancher Prime, RKE2, and SUSE Linux Enterprise Server under your
SUSE subscription. Stacklok supports the Stacklok Enterprise platform that runs
on them.
