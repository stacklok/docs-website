Metrics and tracing export, all off by default. Sprout's strict decoder rejects
unknown fields, so never add a key here the binary does not declare.
`otlp.endpoint` falls back to global.stacklok.telemetry.otlp; `enabled` and
`insecure` are true if either the local or the global value is true.

### `telemetry.otlp.enabled`

**Type:** `bool`

**Default:** `false`

Push metrics to an OTLP collector.

### `telemetry.otlp.endpoint`

**Type:** `string`

**Default:** `""`

Collector endpoint (e.g. "otel-collector.observability:4318"). Required, locally
or via global, when otlp or tracing is enabled.

### `telemetry.otlp.insecure`

**Type:** `bool`

**Default:** `false`

Disable TLS on the OTLP connection. Only for a collector reachable over a
private, trusted network.

### `telemetry.otlp.tracesEndpoint`

**Type:** `string`

**Default:** `""`

Exact URL spans are POSTed to over OTLP/HTTP (no "/v1/traces" appended), e.g.
"https://telemetry.cloudzero.com/v2/telemetry/&#60;sink&#62;". Traces only; its
scheme decides TLS. Needs tracing.enabled; not composed with global.

### `telemetry.otlp.headersSecretRef`

**Type:** `object`

**Default:** `{"key":"headers","name":""}`

Secret holding OTLP export headers for `tracesEndpoint` as
`key=value,key2=value2`. Needs an https `tracesEndpoint` and is refused while
OTLP metrics push is on, which would send this credential to the metrics
collector. `key` defaults to "headers".

### `telemetry.prometheus.enabled`

**Type:** `bool`

**Default:** `false`

Expose a pull-scrapeable /metrics route on its own listener (metrics.port).

### `telemetry.tracing`

**Type:** `object`

**Default:** `{"enabled":false,"exportTimeoutSeconds":0,"samplingRate":0}`

Push traces to the OTLP collector. Off by default.

### `telemetry.tracing.enabled`

**Type:** `bool`

**Default:** `false`

Export spans via OTLP. Requires otlp.endpoint or otlp.tracesEndpoint.

### `telemetry.tracing.samplingRate`

**Type:** `int`

**Default:** `0`

Sampling ratio (0.0-1.0) for requests with no or unsampled inbound trace
context; a sampled inbound traceparent is always honored. 0 samples every
request.

### `telemetry.tracing.exportTimeoutSeconds`

**Type:** `int`

**Default:** `0`

Bound, in seconds, on one OTLP export; 0 keeps the 30s default. Set it above the
destination's worst-case response time, or a slow destination can receive the
same batch twice and double-count spans.

### `telemetry.metrics`

**Type:** `object`

**Default:** `{"port":9464}`

Dedicated /metrics listener, bound whenever prometheus.enabled is true.

### `telemetry.headerLabels`

**Type:** `list`

**Default:** `[]`

Header-to-attribute mappings on the token-usage metric. Values outside
`permitted` fold to "other". Governance and credential headers are refused; use
`claimLabels` for caller identity.

```yaml
Example:
  headerLabels:
    - header: x-stacklok-team
      attribute: team
      permitted: [platform, research]
```

### `telemetry.claimLabels`

**Type:** `list`

**Default:** `[]`

Verified token claims carried as labels on the token-usage metric, read from the
signed token (or, for a virtual key, its owner's directory record). Without
`permitted` the value passes through, so a per-user label is one series per user
and puts personal data in your metrics store. At most 10 entries; a claim that
changes per token or session (jti, nonce, sid) needs `permitted`.

```yaml
Example:
  claimLabels:
    - claim: sub
      attribute: user_id
    - claim: department
      attribute: department
```

### `telemetry.groupLabelAttributes`

**Type:** `list`

**Default:** `[]`

Stamp a directory-resolved group label onto the interaction span under a custom
attribute name instead of its bare name. Each `label` must be in
`directory.groupLabels`, or the gateway refuses to start.

```yaml
Example:
  groupLabelAttributes:
    - label: department
      attribute: cz.context.department
```

### `telemetry.spanAttributes`

**Type:** `list`

**Default:** `[]`

Copy a caller-sent request header onto the interaction span under a chosen
attribute name. The value is client-supplied, so treat it as an attribution
hint, never an identity. Credential and personal-data headers are refused; at
most 20 entries. Needs telemetry.tracing.enabled.

```yaml
Example:
  spanAttributes:
    - header: x-cz-context-project
      attribute: cz.context.project
```

### `auth`

**Type:** `object`

**Default:** `{"issuers":[]}`

Trusted OIDC issuers: issuer, audience, bindingClaim, tokenUse, requiredScope,

```yaml

```

### `directory.endpoint`

**Type:** `string`

**Default:** `""`

Directory gRPC endpoint (host:port), e.g.
"enterprise-server.toolhive-system:9091". Empty with insecure: true inherits
global.stacklok.directoryGrpcEndpoint; empty otherwise disables virtual-key
resolution and group labels. Once one resolves, any JWT caller the directory
does not resolve gets 403.

### `directory.insecure`

**Type:** `bool`

**Default:** `false`

Dial the directory over plaintext instead of TLS. Transport only: the caller
credential comes from tokenProjection. Set true for Enterprise Manager's
cleartext gRPC listener, and to inherit global.stacklok.directoryGrpcEndpoint
when endpoint is empty. With Enterprise Manager caller authentication on, also
set tokenProjection.enabled: true.

### `directory.caBundle.secretName`

**Type:** `string`

**Default:** `""`

Secret holding the PEM bundle that verifies the directory's TLS certificate,
added to the system roots. Required for a TLS dial to an in-cluster endpoint,
whose certificate no public root vouches for. Mounted without a subPath and read
at every reconnect, so a rotated certificate is picked up without restarting the
gateway. Chart-local like directory.endpoint, with no global.stacklok default:
the CA vouches for the address this gateway dials, which may differ from other
charts'.

Key of the bundle in that Secret.

Directory the bundle is mounted into.

PII scanning with Presidio and the scanning-adapter. `scanning.enabled=true`
plus an issuer and a CA bundle is enough for a working scan.

### `scanning.enabled`

**Type:** `bool`

**Default:** `false`

Render the Presidio stack and the scanning-adapter, including a cluster-scoped
ClusterRoleBinding, and wire the gateway's scan hook to it.

### `scanning.audience`

**Type:** `string`

**Default:** `""`

Audience of the token the gateway presents to the adapter. Empty derives
`https://<adapter-service>.<release-namespace>.svc`.

### `scanning.requestAction`

**Type:** `string`

**Default:** `"block"`

Global action when Presidio finds an entity: `block` (403), `redact` (replace
the match with a placeholder) or `log-only`.

### `scanning.placeholder`

**Type:** `string`

**Default:** `""`

Text substituted for a redacted match whose entity sets no placeholder of its
own, at most 64 characters. Empty uses `[REDACTED-<ENTITY>]`, e.g.
`[REDACTED-EMAIL_ADDRESS]`.

### `scanning.entityActions`

**Type:** `list`

**Default:** `[]`

Per-entity overrides of requestAction: `entity`, `action`
(`block|redact|log-only`), optional `placeholder`, and optional `mode`
(`enforce`, default, or `shadow`, which only records the detection).

### `scanning.extractionFailureAction`

**Type:** `string`

**Default:** `"block"`

When the request body's text cannot all be extracted for scanning (invalid JSON,
an unrecognized input item, or text nested over 32 levels): `block` (403) or
`continue`, which forwards the unreachable text unscanned with any PII in it,

### `guardrails.screeningWindowTurns`

**Type:** `string`

**Default:** `nil`

Screen sliding windows of the last N user turns instead of the whole
conversation, an integer of at least 3. Each window's verdict is cached, so on a
warm cache a request costs one Bedrock call against at most N turns rather than
one against every turn so far. Requires verdictCache.enabled with a resolvable
Redis; without a usable cache the adapter screens the whole conversation as it
does when this is unset. Only turns carrying text the user wrote count toward N:
a tool-output, media-only, whitelisted or empty turn takes no slot. Trade-off:
an injection split across more than N text turns is not caught.

### `guardrails.screeningWindowMaxLiveCalls`

**Type:** `string`

**Default:** `nil`

The most live Bedrock calls one windowed request makes, an integer of at
least 1. Unset keeps the adapter default of 3. A warm cache needs one. On a cold
or slow cache, up to this many uncached windows are screened and cached one by
one, oldest first, and any beyond that are screened together in a single call,
so a long conversation stays inside hook.timeout and warms over its next
requests. A cache backend that times out stops being consulted for the rest of
the request, and the reads of one request share a fixed budget, so a slow
backend cannot spend hook.timeout.
