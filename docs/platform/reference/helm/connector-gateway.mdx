### `enterpriseConfig`

**Type:** `object`

**Default:** `nil`

Enterprise configuration for the gateway, written into its config ConfigMap and
strict-decoded at startup, so an unknown field stops the gateway from starting.
Keep secrets out of it: credentials are referenced by environment variable name.
Every install needs `authServer` (the embedded authorization server, with
`allowed_audiences` and Redis `storage`, plus
`vmcpConfig.incomingAuth.type: oidc`), `directory` (the Directory address, with
`directoryTLS.enabled` or the development-only `insecure: true`), and a Redis or
Valkey connection, which the chart fills from `global.redis` or `redis.host`
when a host is set and which you can write as `redis` here. The chart does not
ship Redis or Valkey. The Enterprise Manager connection
(`enterpriseManager.url`) is filled from
`global.stacklok.enterpriseManager.url`; keys you set here override it. Every
tool call is recorded to a durable Redis outbox and sent to the metering ingest.
`outbox.maxLen` tunes the stream length. The ingest address and TLS settings
default to `directory`'s; `metering` overrides them. The chart projects the
ingest's ServiceAccount token unless the dial is cleartext or
`metering.tokenPath` names a token you mount yourself. Other optional sections
are `publishedCimdClients` and `policyWebhooks`. `gateway.id` and
`authServer.issuer` are chart-owned, set from
`global.stacklok.connectorGatewayId` and `global.stacklok.authServerIssuer`, and
setting either here fails the render. The commented example below this key shows
each section.

### `consoleUrl`

**Type:** `string`

**Default:** `""`

The console's public URL, for example `https://console.example.com`. Empty
inherits `global.stacklok.consoleUrl`; a value here wins. It switches on the
reconnect link in a connector credential prompt: a tool call that needs a
Connector whose credential is dead gets
`<consoleUrl>/connectors/<connector id>/connect`. With neither set, the prompt
tells the user to reconnect from the console's Connectors page. Must be an
absolute https URL, or http on a loopback host, with no userinfo, query or
fragment; any other value, inherited or local, stops the gateway from starting.
Set a conforming value here when the global does not conform.

### `appConfig`

**Type:** `object`

**Default:** `{}`

Overrides for the gateway's application configuration, deep-merged over the
configuration the chart builds from the other values; keys here win. Set
`logLevel: debug` to raise log verbosity. `primaryIdp` overrides
`global.stacklok.primaryIdp` for this install. Its `clientClaim` is limited to
`cid`, `client_id`, `azp` or `appid` unless `clientClaimAllowUnsafe: true`. For
an Entra v2.0 issuer, the chart renders `clientClaim: azp` and
`subjectClaim: oid` (scopes must include `profile`) and refuses other values.

### `redis`

**Type:** `object`

### `redis.host`

Hostname, IP address or CNAME of the external Redis or Valkey instance. Empty

### `directoryTLS`

**Type:** `object`

<details>
<summary>Default value</summary>


Chart-managed transport to Directory's gRPC API: mounts the CA bundle, projects

pod restart; the token refreshes in place.

### `directoryTLS.enabled`

**Type:** `bool`

**Default:** `false`

Enable the chart-managed Directory transport: the CA bundle mount, the projected
ServiceAccount token, and the configuration paths that name them.

### `directoryTLS.caBundle.secretName`

**Type:** `string`

**Default:** `""`

Secret holding the PEM bundle that verifies Directory's serving certificate.
Required when enabled. Use a CA-only Secret, not cert-manager's
`<fullname>-grpc-tls`, which also holds the serving private key.

### `directoryTLS.caBundle.key`

**Type:** `string`

**Default:** `"ca.crt"`

Key within that Secret holding the PEM bundle; also names the mounted file. Must
be non-empty and not `tls.key`.

### `directoryTLS.mountPath`

**Type:** `string`

**Default:** `"/etc/directory-tls"`

Directory the CA bundle Secret is mounted into.

### `directoryTLS.tokenMountPath`

**Type:** `string`

**Default:** `"/var/run/secrets/directory"`

Directory the projected ServiceAccount token is mounted into (as `token`).

### `directoryTLS.audience`

**Type:** `string`

**Default:** `"directory-service"`

Audience Directory's caller-auth gate expects. Fixed on the Directory side, so

### `directoryTLS.expirationSeconds`

**Type:** `int`

### `primaryIdpCA.mountPath`

**Type:** `string`

### `nativeSignIn`

**Type:** `object`

**Default:** `{"signIn":{"caBundleRef":{}}}`

Native sign-in, a Connector auth strategy where the user signs in to the
target's own login on a gateway-hosted, brandable page, and each call carries
the session it captured. The experiment
`global.stacklok.experiments.nativeSignIn.enabled` switches it on, on every
release channel. It needs `enterpriseConfig.authServer` with Redis storage and
the KEK (`kek`): sessions are sealed with the KEK in that Redis, and the sign-in
pages are served on the auth server's browser-facing origin. To skip certificate
verification of the login request (lab targets only), set
`enterpriseConfig.nativeSignIn.signIn.insecureSkipVerify`.

### `nativeSignIn.signIn.caBundleRef`

**Type:** `object`

**Default:** `{}`

Additional PEM CA bundle trusted, beside the system roots, for every native
sign-in login endpoint, when the targets sit behind a private CA. Reference
exactly one secretRef or configMapRef, with `key` defaulting to `ca.crt`
(`tls.key` is refused). The chart mounts it and writes its path into the gateway
config. Setting it while the experiment is off fails the render. Rotating the
bundle's contents in place needs a manual pod restart.

### `extraVolumeMounts`

### `kek`

**Type:** `object`

<details>
<summary>Default value</summary>

```yaml
activeVersion: ''
allowGenerateOnUpgrade: false
existingSecret: ''
generate: false
keyringGeneration: ''
value: ''
```

</details>

Key encryption key (KEK) for the embedded auth server's envelope encryption.
Required when the gateway's configuration enables `authServer`. Choose exactly
one source below; losing or replacing the key makes existing credentials
unreadable. See
[Rotate the encryption key](https://docs.stacklok.com/connector-gateway/rotate-encryption-key).

### `kek.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret in the release namespace with key material under `kek`. The
chart does not manage it. Required for Argo CD and render-and-apply workflows.
Restart pods after changing its content; retain old versions during rotation.

### `kek.value`

**Type:** `string`

**Default:** `""`

Inline, base64-encoded key material, in one of two forms. A single key is the
base64 of 32 random bytes, as `openssl rand -base64 32` prints. A version map is
the base64 of a JSON object mapping each version to a base64-encoded 32-byte
key, such as `{"1":"<base64 key>","2":"<base64 key>"}`. Rotation requires the
version map. Prefer `existingSecret`, because Helm release data and
`helm get values` expose inline values.

### `kek.generate`

**Type:** `bool`

**Default:** `false`

Generate and preserve a version-1 key on a live Helm install. Do not use with
`helm template`, Argo CD, or other render-and-apply workflows because they
cannot preserve a key through `lookup`.

### `kek.allowGenerateOnUpgrade`

**Type:** `bool`

**Default:** `false`

Allow generation during an upgrade only for a confirmed first enable. A lookup
miss can also mean missing Secret RBAC or a client-only renderer.

### `kek.activeVersion`

**Type:** `string`

**Default:** `""`

Keyring version new writes seal under; empty means the highest present. Pin it
during a two-phase rotation so no replica writes under a key a peer cannot yet
read.

### `kek.keyringGeneration`

**Type:** `string`

**Default:** `""`

Free-form token hashed into the pod checksum to force a rollout. Required in
existingSecret and generate modes, where Secret content changes are invisible to
the chart: bump it on every rotation phase one.

### `authServerKeys`

**Type:** `object`

<details>
<summary>Default value</summary>

```yaml
allowGenerateOnUpgrade: false
existingSecret: ''
generate: false
rotatedHmacSecretKeys: []
rotatedSigningKeys: []
```

</details>

Durable key material for the embedded auth server. Required when the gateway's
configuration enables `authServer`. Choose exactly one source below.

### `authServerKeys.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret in the release namespace containing `signing-key.pem` (PEM ECDSA
private key) and `hmac-secret` (at least 32 bytes, e.g.
`openssl rand 32 > hmac-secret`). The chart does not manage it. Required for
Argo CD and render-and-apply workflows.

### `authServerKeys.generate`

**Type:** `bool`

**Default:** `false`

Generate and preserve an ECDSA P-256 signing key and a separate 32-byte HMAC
secret on a live Helm install. Do not use with `helm template`, Argo CD, or
other render-and-apply workflows because they cannot preserve generated material
through `lookup`.

### `authServerKeys.allowGenerateOnUpgrade`

**Type:** `bool`

**Default:** `false`

Allow generation during an upgrade only for a confirmed first enable. A lookup
miss can also mean missing Secret RBAC or a client-only renderer.

### `authServerKeys.rotatedHmacSecretKeys`

**Type:** `list`

**Default:** `[]`

Keys in the `existingSecret` Secret holding retired HMAC secrets, still accepted
for outstanding authorization codes and refresh tokens. Requires
`existingSecret`.

### `authServerKeys.rotatedSigningKeys`

**Type:** `list`

**Default:** `[]`

Keys in the `existingSecret` Secret holding retired signing keys, still
published in the JWKS. Requires `existingSecret`. Remove each once its tokens
expire: a listed compromised key keeps forged tokens valid.

### `networkPolicy.enabled`

**Type:** `bool`

**Default:** `false`

Enable a NetworkPolicy for the Connector Gateway pod.

### `networkPolicy.allowExternalEgress`

**Type:** `bool`

**Default:** `true`

Allow all egress. NetworkPolicies are additive, so `true` overrides any cluster
default-deny egress. Set `false` and populate `egress` to lock down this pod,
which holds the KEK and the primary IdP client secret. With the policy enabled,
the render fails when this is `true` and `egress` is non-empty, because the list
would be ignored.

### `networkPolicy.egress`

**Type:** `list`

**Default:** `[]`

Egress rules (NetworkPolicyEgressRule shape) applied when `allowExternalEgress`
is `false`. Must cover DNS and every IdP, Directory, backend, Redis and metering
destination, plus the kube-apiserver when `internalApi.enabled` is true. A
missing rule fails silently at run time. With the policy enabled, the render
fails when this is empty and `allowExternalEgress` is `false`, because the pod
would have no egress at all.
