Configure the console chart with these Helm values.

This reference lists values declared in the chart's default `values.yaml`.
Templates can also accept optional settings and inherited `global` values.

Chart: `toolhive-cloud-ui`. Chart version: `0.24.0`. Generated from the platform
source at `v0.24.0`.

## Values

### `replicaCount`

**Type:** `int`

**Default:** `1`

Number of replicas for the deployment. Ignored when ha.enabled or
autoscaling.enabled is true.

### `ha`

**Type:** `object`

<details>
<summary>Default value</summary>

```yaml
antiAffinityPreset: soft
enabled: false
podDisruptionBudget:
  minAvailable: 1
replicaCount: 2
```

</details>

High availability: replica count, PodDisruptionBudget and anti-affinity
together. The render fails if ha.enabled is true with fewer than 2 replicas,
since a PDB without spare replicas blocks every node drain.

### `ha.enabled`

**Type:** `bool`

**Default:** `false`

Enable HA mode: uses ha.replicaCount, creates a PodDisruptionBudget, and spreads
replicas across nodes and zones.

### `ha.replicaCount`

**Type:** `int`

**Default:** `2`

Replica count used when ha.enabled is true.

### `ha.podDisruptionBudget.minAvailable`

**Type:** `int`

**Default:** `1`

Minimum number of pods that must remain available.

### `ha.antiAffinityPreset`

**Type:** `string`

**Default:** `"soft"`

Node anti-affinity: "soft" (preferred) or "hard" (required). Zone spreading is
always preferred only.

### `networkPolicy`

**Type:** `object`

**Default:** `{"allowExternalEgress":true,"egress":[],"enabled":false}`

NetworkPolicy, off by default. Enable it on clusters whose policy engine
attaches a deny-all policy to pods that have none.

### `networkPolicy.allowExternalEgress`

**Type:** `bool`

**Default:** `true`

Allow all egress traffic. Every destination is a URL you configure, so set false
and list them in `egress` to lock egress down.

### `networkPolicy.egress`

**Type:** `list`

**Default:** `[]`

Egress rules (NetworkPolicyEgressRule shape) applied when allowExternalEgress is
false. Must cover DNS and every configured destination; a missing one fails
silently.

### `betterAuth`

**Type:** `object`

Better Auth session management

### `betterAuth.secret`

**Type:** `string`

**Default:** `""`

Token encryption secret as a plain value, at least 32 characters long. Required
unless `existingSecret` is set. Prefer a Kubernetes Secret via `existingSecret`.
Generate a value with `openssl rand -base64 32`.

### `betterAuth.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret holding the token encryption secret. Takes precedence over
`secret`.

### `betterAuth.existingSecretKey`

**Type:** `string`

**Default:** `"secret"`

Key within existingSecret holding the token encryption secret.

### `betterAuth.url`

**Type:** `string`

**Default:** `""`

Public, browser-reachable URL of the console, used for authentication callbacks.
Required.

### `enterpriseManagerUrl`

**Type:** `string`

**Default:** `""`

Base URL of Enterprise Manager. Required for the administration pages, which
fail without it. Empty inherits global.stacklok.enterpriseManager.url. Once set,
only an active Directory profile may sign in.

### `gatewayApiUrl`

**Type:** `string`

**Default:** `""`

Legacy AI Gateway management API URL, server-to-server (models, liveness). Read
only when AI Gateway v2 isn't installed (`global.stacklok.aiGatewayV2.enabled`);
then required, here or via the config server's `gateway.api_url` (which wins),
for the gateway pages. Do not also set GATEWAY\_\* vars in `env`: that
duplicates the entry.

### `gatewayProxyUrl`

**Type:** `string`

**Default:** `""`

Public AI Gateway proxy URL shown in the CLI setup command and the "My Usage"
banner. With AI Gateway v2 installed it is also the console's gateway backend,
so it must reach AI Gateway v2. Empty inherits `global.stacklok.aiGatewayV2.url`
while AI Gateway v2 is installed. The config server's `gateway.proxy_url` wins
over both when set.

### `connectorGatewayUrl`

**Type:** `string`

**Default:** `""`

Connector Gateway control-plane API URL, e.g.
http://&#60;release&#62;-connector-gateway-control-plane.&#60;namespace&#62;:8090
(not the data-plane Service). The Connectors pages also need
global.stacklok.connectorGateway.enabled. The value is `tpl`-evaluated.

### `thvCliOidcIssuerUrl`

**Type:** `string`

**Default:** `""`

OIDC issuer URL used by the console's Stacklok CLI setup instructions. Set this
and thvCliOidcClientId to enable the setup wizard.

### `thvCliOidcClientId`

**Type:** `string`

**Default:** `""`

Public OAuth client ID used by the Stacklok CLI with PKCE. Set this and
thvCliOidcIssuerUrl to enable the console's setup wizard.

### `thvCliOidcAudience`

**Type:** `string`

**Default:** `""`

Optional OAuth audience included in the CLI setup command. Set it when the LLM
gateway requires a specific JWT audience; empty omits the option.

### `thvCliOidcCallbackPort`

**Type:** `string`

**Default:** `""`

Local OAuth callback port included in the CLI setup command. Set it to match the
redirect URI registered with your IdP; empty uses the CLI default of 8666.

### `redisUrl`

**Type:** `string`

**Default:** `""`

External Redis URL for server-side caching, e.g.
"redis://:password@redis.example.com:6379/0". Without it the SKILL.md preview is
hidden. The URL embeds the password in the pod spec; prefer
redisUrlExistingSecret.

### `redisUrlExistingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret holding the full Redis URL. Takes precedence over redisUrl.

### `redisUrlExistingSecretKey`

**Type:** `string`

**Default:** `"redis-url"`

Key within redisUrlExistingSecret holding the connection URL.
