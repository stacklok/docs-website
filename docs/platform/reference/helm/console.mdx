Configure the console chart with these Helm values.

This reference lists values declared in the chart's default `values.yaml`.
Templates can also accept optional settings and inherited `global` values.

Chart: `toolhive-cloud-ui`. Chart version: `0.31.1`. Generated from the platform
source at `v0.31.1`.

## Values

### `replicaCount`

**Type:** `int`

**Default:** `1`

Number of replicas for the deployment. Ignored when `ha.enabled` or
`autoscaling.enabled` is true.

### `ha`

**Type:** `object`

<details>
<summary>Default value</summary>

```yaml
antiAffinityPreset: soft
enabled: false
podDisruptionBudget:
  minAvailable: 1
replicaCount: 2
```

</details>

High availability: replica count, PodDisruptionBudget and anti-affinity
together. The render fails if `ha.enabled` is true with fewer than 2 replicas,
since a PDB without spare replicas blocks every node drain.

### `ha.enabled`

**Type:** `bool`

**Default:** `false`

Enable HA mode: uses `ha.replicaCount`, creates a PodDisruptionBudget, and
spreads replicas across nodes and zones.

### `ha.replicaCount`

**Type:** `int`

**Default:** `2`

Replica count used when `ha.enabled` is true.

### `ha.podDisruptionBudget.minAvailable`

**Type:** `int`

**Default:** `1`

Minimum number of pods that must remain available.

### `ha.antiAffinityPreset`

**Type:** `string`

**Default:** `"soft"`

Node anti-affinity: `soft` (preferred) or `hard` (required). Zone spreading is
always preferred only.

### `networkPolicy`

**Type:** `object`

**Default:** `{"allowExternalEgress":true,"egress":[],"enabled":false}`

NetworkPolicy, off by default. Enable it on clusters whose policy engine
attaches a deny-all policy to pods that have none.

### `networkPolicy.allowExternalEgress`

**Type:** `bool`

**Default:** `true`

Allow all egress traffic. Every destination is a URL you configure, so set
`false` and list them in `egress` to lock egress down. While this is `true`, the
`egress` list is ignored.

### `networkPolicy.egress`

**Type:** `list`

**Default:** `[]`

Egress rules (NetworkPolicyEgressRule shape) applied when `allowExternalEgress`
is `false`. Must cover DNS and every configured destination; a missing one fails
silently at run time. With the policy enabled, the render fails when this is
empty and `allowExternalEgress` is `false`, because the pod would have no egress
at all.

### `apiBaseUrl`

**Type:** `string`

**Default:** `""`

Registry Server API base URL. Leave it empty: it defaults to
`global.stacklok.registryServer.url`, or to the `registry-api` Service while
`global.stacklok.registryServer.enabled` is true. A set value that differs from
that URL fails the render. Set it only while neither global key is set.
Enterprise Manager's `registry.server_api_url` config wins over it at run time;
with neither, the registry-backed pages have no backend.

### `oidc`

**Type:** `object`

**Default:** `{"additionalProviders":[]}`

OIDC configuration. The primary provider comes from
`global.stacklok.primaryIdp`, including its private-CA `caBundleRef`. Restart
the pods after changing the CA bundle's contents.

### `oidc.additionalProviders`

**Type:** `list`

**Default:** `[]`

Additional OIDC providers users can sign in with, beside the primary provider.
Each entry needs `issuerUrl`, `clientId` and `clientSecret`, and takes an
optional `scopes` (comma-separated; empty uses the primary provider's scopes).
The console skips an entry missing a required field and logs an error. Register
the redirect URI `<console URL>/api/auth/oauth2/callback/oidc-<n>` with each
provider, where the console URL is the effective `betterAuth.url` and `<n>` is
the entry's position plus 1 (`oidc-2` for the first entry). The whole list,
including each `clientSecret`, is written into the Deployment as the plain-text
environment variable `OIDC_ADDITIONAL_PROVIDERS`, readable by anyone who can
read the Deployment. Empty means single-provider mode.

### `betterAuth`

**Type:** `object`

**Default:**
`{"existingSecret":"","existingSecretKey":"secret","secret":"","url":""}`

Console sign-in sessions. The secret signs and encrypts the console's session
cookies, which carry the user's OIDC tokens. Changing it invalidates every
existing session.

### `betterAuth.secret`

**Type:** `string`

**Default:** `""`

Token encryption secret as a plain value, at least 32 characters long. Required
unless `existingSecret` is set. Prefer a Kubernetes Secret via `existingSecret`.
Generate a value with `openssl rand -base64 32`.

### `betterAuth.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret holding the token encryption secret. Takes precedence over
`secret`.

### `betterAuth.existingSecretKey`

**Type:** `string`

**Default:** `"secret"`

Key within `existingSecret` holding the token encryption secret.

### `betterAuth.url`

**Type:** `string`

**Default:** `""`

Public, browser-reachable URL of the console, used for authentication callbacks.
Required. Empty inherits `global.stacklok.consoleUrl`.

### `enterpriseManagerUrl`

**Type:** `string`

**Default:** `""`

Base URL of Enterprise Manager. Required for the administration pages, which
fail without it. Empty inherits `global.stacklok.enterpriseManager.url`. Once
set, only an active Directory profile may sign in.

### `gatewayProxyUrl`

**Type:** `string`

**Default:** `""`

Public AI Gateway proxy URL shown in the CLI setup command and the "My Usage"
banner. It is also the console's gateway backend (model discovery, liveness), so
it must reach AI Gateway v2. Empty inherits `global.stacklok.aiGatewayV2.url`
while AI Gateway v2 is installed. Enterprise Manager's `gateway.proxy_url`
setting wins over both when set.

### `connectorGatewayUrl`

**Type:** `string`

**Default:** `""`

Connector Gateway control-plane API URL, for example
`http://<release>-connector-gateway-control-plane.<namespace>:8090` (not the
data-plane Service). The Connectors pages also need
`global.stacklok.connectorGateway.enabled`. The value is `tpl`-evaluated.

### `frontDoorUrl`

**Type:** `string`

**Default:** `""`

Workspace Front Door API URL, for example
`http://<release>-workspace.<namespace>:8080`, read server-side by the Workspace
pages. Empty leaves Front Door unconfigured, and the Workspace pages then report
it as unavailable. The value is `tpl`-evaluated.

### `thvCliOidcIssuerUrl`

**Type:** `string`

**Default:** `""`

OIDC issuer URL used by the console's Stacklok CLI setup instructions. Set this

### `thvCliOidcClientId`

**Type:** `string`

Public OAuth client ID used by the Stacklok CLI with PKCE. Set this and

### `thvCliOidcAudience`

**Type:** `string`

**Default:** `""`

Optional OAuth audience included in the CLI setup command. Set it when the AI

### `thvCliOidcCallbackPort`

**Type:** `string`

**Default:** `""`

Local OAuth callback port included in the CLI setup command. Set it to match the

### `thvCliDownloadUrl`

**Type:** `string`

**Default:** `""`

Where users download the Stacklok CLI, such as your company's software portal.
The Clients page links to it; empty tells users to get the CLI from their IT
team. Must be an http(s) URL.

### `thvCliSetupEnabled`

**Type:** `bool`

**Default:** `true`

Show the Stacklok CLI setup steps on the Clients page. Set `false` when users
should not install the CLI: the page then offers only the gateway URL and an API

### `branding.config`

**Type:** `object`

File-based branding. Set `enabled: true` and put the branding JSON under `json`,

### `branding.logoUrl`

**Type:** `string`

**Default:** `""`

URL of the logo shown in the console, without a ConfigMap. Overridden by

### `branding.faviconUrl`

**Type:** `string`

**Default:** `""`

URL of the browser favicon, without a ConfigMap. Overridden by `favicon_url` in

### `localSpeechToTextEnabled`

**Type:** `bool`

**Default:** `true`

Workspace chat dictation (voice typing) recognised on the user's device, where
the browser promises it (`SpeechRecognition.processLocally`); the console cannot
verify that promise. The browser downloads its language pack, model data and not
audio, on the first click. Set `false` to stop on-device dictation; with
`thirdPartySpeechToTextEnabled` also `false`, the console offers no dictation.

### `thirdPartySpeechToTextEnabled`

**Type:** `bool`

**Default:** `false`

Workspace chat dictation through the browser's own speech recognition, which may
send the user's audio to a service of the browser's or OS's choosing (Google for
Chrome), with no control over or trace of where it goes. On-device recognition
is still used wherever `localSpeechToTextEnabled` allows it and the browser
offers it. Set `true` to offer dictation in browsers that cannot recognise
speech on the device.
