Use the [platform chart reference](./platform.mdx) when configuring a platform
release. It covers component enablement, shared settings under
`global.stacklok`, and overrides declared in the umbrella chart's default
`values.yaml`.

Component references describe each first-party chart's own defaults. To override
one through the umbrella chart, nest its values under the dependency name or
alias shown below. Operator and Registry Server overlays also contain an
`upstream` block for the chart they wrap. These references cover declared
defaults; they do not expand all values from wrapped or third-party dependency
charts.

## Platform chart

[Platform Helm values](./platform.mdx) covers the umbrella chart used to install
Stacklok Enterprise.
