Configure the platform chart with these Helm values.

This reference lists values declared in the chart's default `values.yaml`.
Templates can also accept optional settings and inherited `global` values.

Chart: `stacklok-enterprise-platform`. Chart version: `0.25.0`. Generated from
the platform source at `v0.25.0`.

## Values

### `replicated.enabled`

**Type:** `bool`

**Default:** `false`

Install the Replicated SDK for licensing, telemetry, and instance health
reporting.

### `replicated.nameOverride`

**Type:** `string`

**Default:** `"stacklok-license-manager"`

Override the Replicated SDK resource name, including its Service name.

### `cloudUi.enabled`

**Type:** `bool`

**Default:** `false`

Install the console subchart.

### `enterpriseManager.enabled`

**Type:** `bool`

**Default:** `false`

Install the Enterprise Manager subchart. Configure the primary IdP issuer and
the expected audience before enabling it.

### `toolhiveOperator.enabled`

**Type:** `bool`

**Default:** `false`

Install the ToolHive operator and its CRD overlay charts.

### `registryServer.enabled`

**Type:** `bool`

**Default:** `false`

Install the standalone Registry Server. Configure its PostgreSQL connection and
credentials before enabling it.

### `preflight.checkEgress`

**Type:** `bool`

**Default:** `false`

Include an advisory HTTP probe of replicated.app. Enable only for installations
with internet access; the probe fails in an air-gapped environment.

### `preflight.enforce`

**Type:** `bool`

**Default:** `false`

Run preflight checks in a Helm hook Job and fail installation or upgrade if a
check fails. Requires global.replicated.dockerconfigjson (without it the image
pull fails and the install hangs) and cluster-scoped read RBAC.

### `preflight.image.repository`

**Type:** `string`

<details>
<summary>Default value</summary>


</details>

Container image repository for the preflight enforcement Job.

### `preflight.image.tag`

**Type:** `string`

**Default:** `""`

Override the preflight image tag. An empty value uses the chart's appVersion.

### `preflight.resources.requests.cpu`

**Type:** `string`

**Default:** `"50m"`

CPU requested by the preflight enforcement Job.

### `preflight.resources.requests.memory`

**Type:** `string`

**Default:** `"128Mi"`

Memory requested by the preflight enforcement Job.

### `preflight.resources.limits.cpu`

**Type:** `string`

**Default:** `"200m"`

CPU limit for the preflight enforcement Job.

### `preflight.resources.limits.memory`

**Type:** `string`

**Default:** `"256Mi"`

Memory limit for the preflight enforcement Job. Increase it on large clusters;
usage scales with namespace and resource count.

### `toolhive-registry-server.preflightDatabaseUri`

**Type:** `string`

**Default:** `""`

PostgreSQL URI for the optional preflight database probe. Supply it only for a
one-off preflight run: a persistent values file stores its password in the
rendered preflight Secret. Empty disables the probe.

### `enterprise-manager.serviceAccount`

**Type:** `object`

**Default:** `{"automount":true,"create":true}`

Dedicated Enterprise Manager ServiceAccount; Connector Gateway's internal API
admits exactly this subject. Renaming it requires setting
connector-gateway.internalApi.allowedSubjects to match.

### `enterprise-manager.grpc.insecure`

**Type:** `bool`

**Default:** `false`

Skip caller authentication on the shared gRPC service (development only; TLS is
grpc.tls.enabled). Must agree with Connector Gateway's directory.insecure.

### `enterprise-manager.grpc.callerAuth.clusterOidcIssuer`

**Type:** `string`

**Default:** `""`

Cluster OIDC issuer used to verify projected ServiceAccount tokens on the shared
gRPC listener. Empty leaves authenticated calls denied unless grpc.insecure is
enabled for development.

ServiceAccount subjects allowed to call gateway registration RPCs, including

all callers.

### `enterprise-manager.grpc.tls.enabled`

**Type:** `bool`

**Default:** `false`

Enable the TLS listener on the shared gRPC service. Required when
directory.kek.enabled is true. Configure exactly one certificate source:
issuerRef.name or existingSecret.

### `enterprise-manager.grpc.tls.issuerRef.name`

**Type:** `string`

**Default:** `""`

cert-manager issuer name for the gRPC serving certificate. Use this or
existingSecret as the certificate source.

### `enterprise-manager.grpc.tls.issuerRef.kind`

**Type:** `string`

**Default:** `"ClusterIssuer"`

Kind of the cert-manager issuer for the gRPC serving certificate: ClusterIssuer
or Issuer.

### `enterprise-manager.grpc.tls.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret containing tls.crt and tls.key for the gRPC listener. Use this
or issuerRef.name as the certificate source.

### `enterprise-manager.directory.enabled`

**Type:** `bool`

**Default:** `false`

Enable the Enterprise Manager directory service.

### `enterprise-manager.directory.scimExternalBaseURL`

**Type:** `string`

**Default:** `""`

External HTTPS base URL used in SCIM Location headers and member $ref values.
Set it for clients that require absolute URLs.

### `enterprise-manager.directory.issuers`

**Type:** `list`

**Default:** `[]`

Additional issuers accepted by the directory. The primary IdP is configured
through global.stacklok.primaryIdp.

### `enterprise-manager.directory.hmac.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret containing the virtual-key HMAC key. Empty lets the application
create or reuse its managed Secret at startup.

### `enterprise-manager.directory.hmac.existingSecretKey`

**Type:** `string`

**Default:** `"hmac-key"`

Key within the existing HMAC Secret that contains the HMAC key material.

### `enterprise-manager.directory.kek.enabled`

**Type:** `bool`

**Default:** `false`

Enable envelope encryption for directory-managed credentials. Requires gRPC TLS
and exactly one KEK source: existingSecret or generate.

### `enterprise-manager.directory.kek.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret containing the directory key encryption key (KEK). Use this for
render-and-apply GitOps so repeated renders retain the same key.

### `enterprise-manager.directory.kek.existingSecretKey`

**Type:** `string`

**Default:** `"kek"`

Key within the existing Secret that contains the directory KEK.

### `enterprise-manager.directory.kek.generate`

**Type:** `bool`

**Default:** `false`

Generate the directory KEK through Helm. Use existingSecret for render-and-apply
GitOps, where repeated generation would invalidate stored credentials.

### `enterprise-manager.directory.kek.externallyManagedRBAC`

**Type:** `bool`

**Default:** `false`

Acknowledge that external RBAC restricts access to the directory KEK Secret.
Enable only after supplying the required access controls.

### `enterprise-manager.directory.kek.externallyManagedNetworkPolicy`

**Type:** `bool`

**Default:** `false`

Acknowledge that an external NetworkPolicy restricts access to the directory's
credential service. Enable only after supplying the required network controls.

### `enterprise-manager.directory.connectorVerification.enabled`

**Type:** `bool`

**Default:** `true`

Verify a Connector's endpoint with a live TCP connection before marking it
available. Disabling this bypasses the reachability check; existing failed
Connectors require re-saving to be verified again.

### `enterprise-manager.directory.connectorVerification.dialTimeout`

**Type:** `string`

**Default:** `""`

Timeout for Connector endpoint verification, expressed as a Go duration such as
15s. Empty uses the application default of 5s.

### `enterprise-manager.directory.connectorVerification.allowedPrivateRanges`

**Type:** `list`

**Default:** `[]`

CIDR ranges exempted from the Connector reachability check's private-address
deny-list. Never exempt loopback, link-local, or cloud metadata addresses.

### `toolhive-cloud-ui.enterpriseManagerUrl`

**Type:** `string`

**Default:** `""`

Enterprise Manager HTTP API base URL, e.g.
http://enterprise-manager.toolhive-system:9090. Empty inherits
global.stacklok.enterpriseManager.url. Either source enables the console pages
backed by it and Directory session authorization.

Connector Gateway control-plane API URL for the console. Defaults to the derived

### `connector-gateway.enabled`

**Type:** `bool`

**Default:** `false`

Fallback installation toggle when global.stacklok.connectorGateway.enabled is
absent. The explicit false default keeps the gateway disabled when
global.stacklok is null.

### `connector-gateway.internalApi`

**Type:** `object`

**Default:** `{"deriveEnterpriseManagerSubject":true,"enabled":true}`

Internal API Enterprise Manager calls to revoke upstream tokens and refresh
Connector tools; it must stay enabled. With networkPolicy.enabled and
allowExternalEgress false, allow egress to the kube-apiserver or every
Disconnect returns 502.

### `ai-gateway-v2.enabled`

**Type:** `bool`

**Default:** `false`

Fallback installation toggle when global.stacklok.aiGatewayV2.enabled is absent.
The explicit false default keeps this data plane disabled when global.stacklok
is null.

### `ai-gateway-v2.scanning.enabled`

**Type:** `bool`

**Default:** `false`

Install Presidio and the scanning adapter, and enable the gateway's scanning
hook. Configure the shared webhook issuer and CA bundle or chart-local TLS
overrides.

### `ai-gateway-v2.guardrails.enabled`

**Type:** `bool`

**Default:** `false`

Install the Bedrock guardrails adapter and enable the gateway's guardrails hook.
Configure the Bedrock guardrail ID, version, and region, plus the shared webhook
TLS identity or chart-local overrides.

### `global.stacklok.sessionHeaders`

**Type:** `list`

**Default:** `[]`

Ordered request headers used to correlate conversations; the first non-empty
wins. Empty uses x-claude-code-session-id, x-mecatl-root-session-id,
x-mecatl-session-id, session-id. Changing it rolls the Envoy data plane.

### `global.stacklok.directoryGrpcEndpoint`

**Type:** `string`

**Default:** `""`

Enterprise Manager directory gRPC address on its cleartext listener, for
group-label telemetry, e.g. enterprise-manager.toolhive-system.svc:9091.
Authorize each calling main processor in
enterprise-manager.grpc.callerAuth.saSubjectAllowlist. AI Gateway v2 inherits it
when its directory.endpoint is empty and directory.insecure is true, and under
caller authentication then needs directory.tokenProjection.enabled and its
ServiceAccount in that allowlist.

### `global.stacklok.directoryGrpcInsecure`

**Type:** `bool`

**Default:** `false`

Omit the main processor's projected ServiceAccount token for directory calls
during local development. Leave false for authenticated installations; a
directory that requires caller authentication refuses these calls.

### `global.stacklok.enterpriseManager`

**Type:** `object`

**Default:**
`{"platformSettings":{"connectivityPollIntervalSeconds":5},"url":""}`

Shared Enterprise Manager HTTP configuration propagated to adopting subcharts.
Configure directory gRPC through directoryGrpcEndpoint.

### `global.stacklok.enterpriseManager.url`

**Type:** `string`

**Default:** `""`

Enterprise Manager HTTP base URL, without a path suffix. Callers append their
endpoint paths. The console inherits it when
toolhive-cloud-ui.enterpriseManagerUrl is empty. Empty disables features that
require this address, including Gateway connectivity enforcement.

### `global.stacklok.enterpriseManager.platformSettings`

**Type:** `object`

**Default:** `{"connectivityPollIntervalSeconds":5}`

Defaults for Enterprise Manager's administration-managed platform settings,
including the interval used to poll Gateway connectivity state.

### `global.stacklok.experiments.insightsClassification.enabled`

**Type:** `bool`

**Default:** `false`

Enable the experimental conversation-capture webhook, subject to the
release-channel guard and scanning requirements.

### `global.stacklok.experiments.insightsClassification.allowFailOpenScanning`

**Type:** `bool`

**Default:** `false`

Allow conversation capture when scanning is configured to continue after a
pipeline failure. Failed stages can leave stored request bodies unredacted; the
waiver preserves the checks requiring an active redaction provider and a
redacting detection action.

### `global.stacklok.experiments.budgetsSpendExport.enabled`

**Type:** `bool`

**Default:** `false`

Enable the experimental administration endpoint for exporting budget spend as
CSV.

### `global.stacklok.experiments.workspace.enabled`

**Type:** `bool`

**Default:** `false`

Enable the experimental Workspace pages in the cloud UI. Subject to the
release-channel guard: it stays off on the Stable channel.

### `global.stacklok.aiGateway.enabled`

**Type:** `bool`

**Default:** `false`

Install the Envoy-based AI Gateway operator and CRDs, and expose its capability
to sibling components.

### `global.stacklok.connectorGateway.enabled`

**Type:** `bool`

**Default:** `false`

Install Connector Gateway and expose its capability to sibling components. Also
set connectorGatewayId and authServerIssuer.

### `global.stacklok.aiGatewayV2.enabled`

**Type:** `bool`

**Default:** `false`

Install the AI Gateway v2 data plane. Enabling both AI Gateway implementations
requires acknowledgeBothDataPlanes and distinct front doors.

### `global.stacklok.aiGatewayV2.url`

**Type:** `string`

**Default:** `""`

AI Gateway v2's public URL, e.g. https://ai-gateway.example.com. The console
reads models and health from it, and shows it in the CLI setup command.
ai-gateway-v2's httpRoute.hostname defaults to its host. A local
toolhive-cloud-ui.gatewayProxyUrl or httpRoute.hostname wins.

### `global.stacklok.acknowledgeBothDataPlanes`

**Type:** `bool`

**Default:** `false`

Allow both AI Gateway implementations during a deliberate side-by-side
migration. Configure distinct front doors and maintain separate provider routes.
AI Gateway v2 has no AIPolicy authorization; its Bedrock guardrails and Presidio
scanning require their own toggles. Both data planes consume resources while
installed.

### `global.stacklok.primaryIdp.issuer`

**Type:** `string`

**Default:** `""`

Corporate OIDC issuer URL shared by the console, Connector Gateway's primary
IdP, and Enterprise Manager.

### `global.stacklok.primaryIdp.clientId`

**Type:** `string`

**Default:** `""`

OAuth client ID for the console's confidential client and the primary IdP
integration.

### `global.stacklok.primaryIdp.clientSecretRef.name`

**Type:** `string`

**Default:** `""`

Existing Secret containing the corporate IdP OAuth client secret.

### `global.stacklok.primaryIdp.clientSecretRef.key`

**Type:** `string`

**Default:** `"client-secret"`

Key within the existing Secret that contains the corporate IdP client secret.

### `global.stacklok.primaryIdp.scopes`

**Type:** `string`

**Default:** `""`

Comma-separated OIDC scopes requested from the primary IdP.

### `global.stacklok.primaryIdp.clientClaim`

**Type:** `string`

**Default:** `""`

Access-token claim used to identify the OAuth client on Connector Gateway's
tools route. Empty checks cid and client_id; supported explicit values are cid,
client_id, azp, and appid.

### `global.stacklok.primaryIdp.clientClaimAllowUnsafe`

**Type:** `bool`

**Default:** `false`

Allow a clientClaim outside the supported list. Configure only when the IdP's
claim reliably identifies the requesting client; a claim shared across clients
can defeat client validation. Supply a boolean.

### `global.stacklok.primaryIdp.subjectClaim`

**Type:** `string`

**Default:** `""`

Token claim Connector Gateway's primary-IdP upstream resolves user subjects on
until the catalog primary activates; Directory's matching binding_claim governs
after. Empty uses sub, or oid on Microsoft Entra ID.

### `global.stacklok.primaryIdp.allowPrivateIps`

**Type:** `bool`

**Default:** `false`

Allow primary-IdP discovery on private addresses. Applies to this IdP's
Connector Gateway integration, including its directory-synthesized
configuration; supply a boolean value.

### `global.stacklok.primaryIdp.caBundleRef`

**Type:** `object`

**Default:** `{}`

Additional PEM CA bundle for the primary IdP, read by the console and Connector
Gateway. Reference exactly one secretRef or configMapRef, with key defaulting to
ca.crt. Enterprise Manager uses its own trustedCABundle. Restart consumers after
rotating bundle contents without changing the reference.

### `global.stacklok.connectorGatewayId`

**Type:** `string`

**Default:** `""`

Stable, deployment-specific Connector Gateway identifier, shared with the
console. Required when the gateway is enabled. Supply a string without colons;
changing it identifies a different gateway installation.

### `global.stacklok.authServerIssuer`

**Type:** `string`

**Default:** `""`

Public issuer URL for Connector Gateway's embedded authorization server.
Required when the gateway is enabled. OAuth callbacks use this URL with
/oauth/callback appended. Tenant path prefixes are supported; userinfo, query
strings, and fragments are rejected.

### `global.stacklok.audit.enabled`

**Type:** `bool`

**Default:** `false`

Enable structured audit events in components that adopt the global audit
configuration. A local audit block replaces the global block in full. MCPServer
and AIGateway custom resources require their own audit configuration.

### `global.stacklok.audit.component`

**Type:** `string`

**Default:** `""`

Default audit event-source label for adopting components. Empty uses each
component's own fallback label.

### `global.stacklok.audit.excludeEventTypes`

**Type:** `list`

**Default:** `[]`

Audit event types excluded from emission by adopting components.

### `global.stacklok.audit.includeRequestData`

**Type:** `bool`

**Default:** `false`

Include request payloads in audit events emitted by adopting components. Payload
capture is a separate opt-in from audit.enabled.

### `global.stacklok.audit.includeResponseData`

**Type:** `bool`

**Default:** `false`

Include response payloads in audit events emitted by adopting components.
Payload capture is a separate opt-in from audit.enabled.

### `global.stacklok.audit.maxDataSize`

**Type:** `int`

**Default:** `0`

Maximum size of request or response payload data included in audit events. Zero
defers to the adopting component's default.

### `global.stacklok.telemetry.otlp.enabled`

**Type:** `bool`

**Default:** `false`

Enable OpenTelemetry Protocol (OTLP) export in adopting components. Global true
enables export even when a local toggle is false; the AI Gateway operator's own
local OTLP block replaces the global block in full.

### `global.stacklok.telemetry.otlp.endpoint`

**Type:** `string`

**Default:** `""`

OTLP collector endpoint used when an adopting component has no local endpoint.
Workload custom resources require their own telemetry configuration.

### `global.stacklok.telemetry.otlp.protocol`

**Type:** `string`

**Default:** `""`

OTLP transport for the AI Gateway operator's own telemetry: grpc or
http/protobuf. Empty uses its default; other current adopters do not read this
setting.

### `global.stacklok.telemetry.otlp.insecure`

**Type:** `bool`

**Default:** `false`

Allow an insecure OTLP transport in adopting components. Global true takes
effect even when a local flag is false; the AI Gateway operator's own local OTLP
block replaces the global block in full.

### `global.webhooks.issuerRef.name`

**Type:** `string`

**Default:** `""`

Shared cert-manager issuer for webhook serving certificates. Required when
Enterprise Manager webhook TLS is enabled.

### `global.webhooks.issuerRef.kind`

**Type:** `string`

**Default:** `"ClusterIssuer"`

Kind of the shared cert-manager issuer: ClusterIssuer or Issuer. A namespaced
Issuer must exist in every namespace where a consumer creates a Certificate,
including namespaces containing AIGateway resources.

### `global.webhooks.caBundleSecret`

**Type:** `string`

**Default:** `""`

Secret containing the shared webhook issuer's CA certificate under ca.crt.
Create it in each namespace where a consumer mounts it.

### `global.redis.host`

**Type:** `string`

**Default:** `""`

Redis or Valkey host shared by components that have no local Redis address.
Empty keeps the global connection inactive.

### `global.redis.port`

**Type:** `int`

**Default:** `6379`

Port for the shared Redis or Valkey connection.

### `global.redis.clusterMode`

**Type:** `bool`

**Default:** `false`

Use the Redis Cluster protocol for the shared Redis or Valkey host.

### `global.redis.username`

**Type:** `string`

**Default:** `""`

Redis ACL username. Pair with existingSecret for username-and-password
authentication; an empty username with a password uses password-only
authentication.

### `global.redis.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret containing the Redis password. Create it in every consumer pod's
namespace. The AI Gateway data plane requires the fixed Secret name redis-auth.

### `global.redis.existingSecretKey`

**Type:** `string`

**Default:** `"redis-password"`

Key containing the Redis password. The AI Gateway data plane requires
redis-password; other adopters read this setting.

### `global.redis.tls.enabled`

**Type:** `bool`

**Default:** `false`

Enable TLS for shared Redis or Valkey connections in adopting components.

### `global.postgres.host`

**Type:** `string`

**Default:** `""`

PostgreSQL host used by components that have no local database host. Empty keeps
the global connection inactive.

### `global.postgres.port`

**Type:** `int`

**Default:** `5432`

Port for the shared PostgreSQL connection.

### `global.postgres.sslMode`

**Type:** `string`

**Default:** `"require"`

PostgreSQL TLS mode used by adopting components when no local mode is
configured.

### `global.postgres.existingSecret`

**Type:** `string`

**Default:** `""`

Existing Secret containing the PostgreSQL password, used when a component has no
local credential configuration.

### `global.postgres.existingSecretKey`

**Type:** `string`

**Default:** `"postgres-password"`

Key within the existing Secret containing the PostgreSQL password.

### `global.postgres.dynamicAuth`

**Type:** `object`

**Default:** `{}`

Shared dynamic database authentication settings for Enterprise Manager, used
when its local database.dynamicAuth is unset. Configure awsRdsIam.region for AWS
RDS IAM authentication. Registry Server requires its own
upstream.config.database.dynamicAuth setting.
