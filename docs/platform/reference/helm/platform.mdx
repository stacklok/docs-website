Configure the platform chart with these Helm values.

This reference lists values declared in the chart's default `values.yaml`.
Templates can also accept optional settings and inherited `global` values.

Chart: `stacklok-enterprise-platform`. Chart version: `0.31.1`. Generated from

### `platformMcp.image.tag`

**Type:** `string`

**Default:** `""`

Override the image tag. An empty value uses the chart's appVersion.

### `platformMcp.audience`

**Type:** `string`

**Default:** `""`

Audience that each endpoint's ToolHive proxy accepts, which is the audience
Enterprise Manager accepts, since the proxy forwards the caller's token to it.
Empty uses `enterprise-manager.idpConfig.audience`. The render fails when both
are empty and an endpoint renders. The issuer comes from
`global.stacklok.primaryIdp`.

### `platformMcp.endpoints`

**Type:** `object`

**Default:** `{}`

The endpoints to run, by name. Each is one MCPServer that runs the toolsets
listed in its required `toolsets` (a comma-separated list; a server with none
refuses to start). It also takes an optional `env` map of extra server settings
and an optional `resources` block with `requests` and `limits` for `cpu` and
`memory` only. The `env` settings are `PLATFORM_MCP_LOG_LEVEL` (`debug`, `info`,
`warn` or `error`; default `info`), `PLATFORM_MCP_READ_HEADER_TIMEOUT` (default
`5s`), `PLATFORM_MCP_READ_TIMEOUT` (default `15s`), `PLATFORM_MCP_WRITE_TIMEOUT`
(default `15s`, at most `20s`, or the render fails), `PLATFORM_MCP_IDLE_TIMEOUT`
(default `60s`), `PLATFORM_MCP_MAX_HEADER_BYTES` (default `16384`) and
`PLATFORM_MCP_MAX_BODY_BYTES` (default `262144`). The chart sets
`PLATFORM_MCP_TOOLSETS` and `PLATFORM_MCP_LISTEN_ADDR` itself and fails the
render when `env` sets either. The server checks the other values at startup.
Empty runs the default `admin` endpoint while Enterprise Manager is enabled.
Setting any endpoint replaces the default.

### `platformMcp.networkPolicy.enabled`

**Type:** `bool`

**Default:** `true`

Render a NetworkPolicy for each endpoint. It admits the endpoint's own pods,
Connector Gateway and Enterprise Manager (Enterprise Manager's directory
verifies the endpoint when an Admin saves the Connector). The last two reach the
proxy port only, never the server pod behind it.

### `platformMcp.networkPolicy.connectorGateway.namespace`

**Type:** `string`

**Default:** `""`

Namespace Connector Gateway runs in. Empty means the release namespace.

### `platformMcp.networkPolicy.connectorGateway.podSelector`

**Type:** `object`

**Default:** `{}`

Pod selector matching the Connector Gateway pods. Empty selects the pods by the
name label of the `connector-gateway` subchart, including its `nameOverride`.

### `platformMcp.networkPolicy.enterpriseManager.namespace`

**Type:** `string`

**Default:** `""`

Namespace Enterprise Manager runs in. Empty means the release namespace.

### `platformMcp.networkPolicy.enterpriseManager.podSelector`

**Type:** `object`

**Default:** `{}`

Pod selector matching the Enterprise Manager pods. Empty selects the pods by the
name label of the `enterprise-manager` subchart, including its `nameOverride`.

### `platformMcp.networkPolicy.extraIngress`

**Type:** `list`

**Default:** `[]`

Extra ingress rules merged into every endpoint's policy. The policy selects the
proxy pod and the server pod behind it, so each rule must list its ports, and
the only port it may list is TCP 8080, the proxy port, with no `endPort` and no
named port: any other port can reach the server pod and skip the proxy's token
check. The render fails for a rule that does not.

### `enterpriseManager.enabled`

**Type:** `bool`

**Default:** `false`

Install Enterprise Manager when `global.stacklok.enterpriseManager.enabled` is
unset. Prefer the global key. The render fails when the global key is false and
this is true.

### `registryServer.enabled`

**Type:** `bool`

**Default:** `false`

Install the standalone Registry Server when
`global.stacklok.registryServer.enabled` is unset. Prefer the global key; the
install notes warn while this one installs it. The render fails when the global
key is false and this is true. No subchart can read this key, so it derives no
registry URL: with it alone, set `global.stacklok.registryServer.url`, or the
render fails while the console or Workspace would get no registry URL.

### `preflight.checkEgress`

**Type:** `bool`

**Default:** `false`

Include an advisory HTTP probe of `replicated.app`. Enable only for
installations with internet access; the probe fails in an air-gapped
environment.

### `preflight.enforce`

**Type:** `bool`

**Default:** `false`

Run preflight checks in a Helm hook Job and fail installation or upgrade if a
check fails. Requires `global.replicated.dockerconfigjson` (without it the image
pull fails and the install hangs) and cluster-scoped read RBAC.

### `enterprise-manager.serviceAccount.create`

**Type:** `bool`

**Default:** `true`

**Type:** `bool`

this is false.

**Type:** `bool`

Connector Gateway's `directory.insecure` setting.

Front Door URL for the Workspace pages, derived from the `workspace` subchart's

### `toolhive-cloud-ui.localSpeechToTextEnabled`

**Type:** `bool`

**Default:** `true`

Workspace chat dictation (voice typing) recognized on the user's device, where
the browser promises it (`SpeechRecognition.processLocally`); the console cannot
verify that promise. The browser downloads its language pack, model data and not
audio, on the first click. Set false to stop on-device dictation; with
`thirdPartySpeechToTextEnabled` also false, the console offers no dictation.

### `toolhive-cloud-ui.thirdPartySpeechToTextEnabled`

**Type:** `bool`

**Default:** `false`

Workspace chat dictation through the browser's own speech recognition, which may
send the user's audio to a service of the browser's or OS's choosing (Google for
Chrome), with no control over or trace of where it goes. On-device recognition
is still used wherever `localSpeechToTextEnabled` allows it and the browser
offers it. Set true to offer dictation in browsers that cannot recognize speech
on the device.

### `workspace.sep.directory.endpoint`

**Type:** `string`

**Default:** `<host>:9443` while `global.stacklok.enterpriseManager.enabled` is

**Type:** `string`

**Default:** `http://<host>` while `global.stacklok.enterpriseManager.enabled`

Enterprise Manager origin serving the connections API that Workspace calls.
Defaults, while `global.stacklok.enterpriseManager.enabled` is on, to Enterprise
Manager's HTTP Service on port 80: `http://` and the host of
`workspace.sep.directory.endpoint`'s default. The render fails when that host is
not Enterprise Manager's Service or `enterprise-manager.service.port` is not 80.
Set it then, when Enterprise Manager runs elsewhere, or to an `https` origin,
which Workspace verifies with `workspace.sep.caSecret`.

**Type:** `object`

**Type:** `string`

### `global.stacklok.enterpriseManager.platformSettings.connectivityPollIntervalSeconds`

**Type:** `int`

**Default:** `5`

for the Gateway connectivity state an Admin sets, which decides whether the
gateway serves traffic. Applies only while
`global.stacklok.enterpriseManager.url` is set. A disconnect takes effect within
one interval. Lower it for faster disconnects, at the cost of more requests to
Enterprise Manager from every gateway replica. Connector Gateway refuses to

### `global.stacklok.experiments.approvals.enabled`

**Type:** `bool`

**Default:** `false`

Enable the experimental tool-call approvals. A gated tool call is denied until
the signed-in user approves that exact call in the console, then allowed once.
One switch turns on both halves: Enterprise Manager hosts the approval service
(it stores records in `global.redis`, links users to
`global.stacklok.consoleUrl` and serves the HTTPS listener) and Connector
Gateway calls it as a policy webhook (it trusts
`global.webhooks.caBundleSecret`). Needs `tools` below, Enterprise Manager
installed with `directory.enabled`, `global.redis.host` and
`global.stacklok.primaryIdp.clientId`: only a token issued to that client, the
console, can read or approve a request. Its client claim is
`primaryIdp.clientClaim` (`cid`, `client_id` or `azp`). The gateway builds
Enterprise Manager's Service and Secret names from the host of
`global.stacklok.enterpriseManager.url` when that host is a Service name
(`<svc>`, `<svc>.<ns>`, `<svc>.<ns>.svc[.cluster.local]`), else from the release
name. With a `nameOverride` or `fullnameOverride` on `enterprise-manager`, set
that URL to the renamed Service on its `service.port` (80 by default), for
example `http://enterprise-server.<ns>.svc`, or the `enterprise-manager` render
refuses the experiment. The URL is also Enterprise Manager's address for AI
Gateway, Connector Gateway and the console. A URL naming any other Service fails
the same render, because the gateway would call that Service for approvals. The
chart generates the HMAC secret and keeps it across upgrades. A renderer that
cannot read the cluster, such as a GitOps tool, generates a new secret on every
sync, which briefly denies gated calls while the two pods pick it up. Subject to
the release-channel guard: it stays off on the Stable channel.

### `global.stacklok.experiments.approvals.tools`

**Type:** `list`

**Default:** `[]`

Tool-name globs that need approval, matched against the served or the
backend-local tool name, for example `["github_delete_*"]`. Required while
approvals is on: an empty list would send every tool call to the approval
service.

### `global.stacklok.experiments.approvals.approvalTtl`

**Type:** `string`

**Default:** `""`

How long an approval lasts unused before it expires: a whole number and a unit,
such as `90s`, `10m` or `1h`. Empty keeps the default of five minutes. The limit
is one hour.

### `global.stacklok.connectorGateway.workloadIdentity.enabled`

**Type:** `bool`

**Default:** `true`

**Type:** `bool`

**Default:** `false`

Install AI Gateway.

### `global.stacklok.aiGatewayV2.url`

**Type:** `string`

**Default:** `""`

AI Gateway's public URL, for example `https://ai-gateway.example.com`. The
console reads models and health from it, and shows it in the CLI setup command.
`ai-gateway-v2.httpRoute.hostname` defaults to its host. A local
`toolhive-cloud-ui.gatewayProxyUrl` or `ai-gateway-v2.httpRoute.hostname` wins.

### `global.stacklok.aiGatewayV2.maxFrameBytes`

**Type:** `int`

**Default:** `10485760`

Largest SSE frame, in bytes, on AI Gateway's streaming responses: an integer
from 1048576 (1 MiB) to 16777216 (16 MiB). AI Gateway caps each frame it reads
from a provider, and each non-streaming response body, at it, and Workspace caps
each frame it reads from the gateway. The OpenAI Responses API repeats the
request's tool schemas in its lifecycle frames, so a frame grows with an agent's
tool surface. A stream holds a few copies of its largest frame, and AI Gateway's
pod is limited to 256Mi and Workspace's to 512Mi, so raise
`ai-gateway-v2.resources` and `workspace.resources` before raising this value.

### `global.stacklok.consoleUrl`

**Type:** `string`

**Default:** `""`

The console's public, browser-reachable URL, for example
`https://console.example.com`. The console inherits it as
`toolhive-cloud-ui.betterAuth.url`, and a local `betterAuth.url` wins. Connector
Gateway inherits it as `connector-gateway.consoleUrl`, which switches on the
reconnect link in a connector credential prompt; a local
`connector-gateway.consoleUrl` wins. The gateway accepts only an absolute
`https` URL, or `http` on a loopback host, with no userinfo, query or fragment;
an inherited value outside that stops it from starting. Workspace inherits it as
`workspace.sep.callbackBaseUrl`, where the Connector Gateway sign-in returns the
browser; a local value wins.
