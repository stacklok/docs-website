### `global.stacklok.experiments.approvals.enabled`

**Type:** `bool`

**Default:** `false`

Enable the experimental tool-call approvals. A gated tool call is denied until
the signed-in user approves that exact call in the console, then allowed once.
One switch turns on both halves: Enterprise Manager hosts the approval service
(it stores records in global.redis, links users to global.stacklok.consoleUrl
and serves the HTTPS listener) and Connector Gateway calls it as a policy
webhook (it trusts global.webhooks.caBundleSecret). Needs tools below,
Enterprise Manager installed with directory.enabled, global.redis.host and
global.stacklok.primaryIdp.clientId: only a token issued to that client, the
console, can read or approve a request. Its client claim is
primaryIdp.clientClaim (cid, client_id or azp). The gateway builds Enterprise
Manager's Service and Secret names from the host of
global.stacklok.enterpriseManager.url when that host is a Service name
(&#60;svc&#62;, &#60;svc&#62;.&#60;ns&#62;,
&#60;svc&#62;.&#60;ns&#62;.svc[.cluster.local]), else from the release name.
With a nameOverride or fullnameOverride on enterprise-manager, set that URL to
the renamed Service on its service.port (80 by default), for example
http://enterprise-server.&#60;ns&#62;.svc, or the enterprise-manager render
refuses the experiment. The URL is also Enterprise Manager's address for
ai-gateway-v2, connector-gateway and cloud-ui. A URL naming any other Service
fails the same render, because the gateway would call that Service for
approvals. The chart generates the HMAC secret and keeps it across upgrades. A
renderer that cannot read the cluster, such as a GitOps tool, generates a new
secret on every sync, which briefly denies gated calls while the two pods pick
it up. Subject to the release-channel guard: it stays off on the Stable channel.

the release-channel guard: it stays off on the Stable channel.

### `global.stacklok.connectorGateway.enabled`

### `global.stacklok.connectorGateway.workloadIdentity.enabled`

**Type:** `bool`

**Default:** `true`

Let a Directory service account call the Connector Gateway with its workload's
own projected ServiceAccount token. Turns on the gateway setting, its
issuer-discovery ClusterRoleBinding and API-server token mount, and adds the

### `global.stacklok.registryServer.url`

**Type:** `string`

**Type:** `bool`

**Default:** `false`

Install the AI Gateway v2 data plane.

### `global.stacklok.aiGatewayV2.url`

**Type:** `string`

**Default:** `""`

AI Gateway v2's public URL, e.g. https://ai-gateway.example.com. The console
reads models and health from it, and shows it in the CLI setup command.
ai-gateway-v2's httpRoute.hostname defaults to its host. A local
toolhive-cloud-ui.gatewayProxyUrl or httpRoute.hostname wins.

### `global.stacklok.aiGatewayV2.maxFrameBytes`

**Type:** `int`

**Default:** `10485760`

Largest SSE frame, in bytes, on the AI Gateway's streaming responses: an integer
from 1048576 (1 MiB) to 16777216 (16 MiB). ai-gateway-v2 caps each frame it
reads from a provider, and each non-streaming response body, at it, and
Workspace each frame it reads from the gateway. The OpenAI Responses API repeats
the request's tool schemas in its lifecycle frames, so a frame grows with an
agent's tool surface. A stream holds a few copies of its largest frame, and
ai-gateway-v2's pod is limited to 256Mi and Workspace's to 512Mi, so raise
ai-gateway-v2.resources and workspace.resources before raising this value.

### `global.stacklok.consoleUrl`

**Type:** `string`

**Default:** `""`

The console's public, browser-reachable URL, e.g. https://console.example.com.
The console inherits it as toolhive-cloud-ui.betterAuth.url, and a local
betterAuth.url wins. Connector Gateway inherits it as
connector-gateway.consoleUrl, which switches on the reconnect link in a
connector credential prompt; a local connector-gateway.consoleUrl wins. The
gateway accepts only an absolute https URL, or http on a loopback host, with no
userinfo, query or fragment; an inherited value outside that stops it from
starting. Workspace inherits it as workspace.sep.callbackBaseUrl, where the
Connector Gateway sign-in returns the browser; a local value wins.
