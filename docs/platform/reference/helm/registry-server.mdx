Configure the Registry Server chart with these Helm values.

This reference lists values declared in the chart's default `values.yaml`.
Templates can also accept optional settings and inherited `global` values.

Chart: `toolhive-registry-server`. Chart version: `0.31.1`. Generated from the
platform source at `v0.31.1`.

## Values

### `ha`

**Type:** `object`

**Default:** `{"podDisruptionBudget":{"minAvailable":1}}`

High availability for the registry server. Set the replica count with
`upstream.replicaCount`; every replica serves the API, and a PodDisruptionBudget
renders only above one replica.

### `ha.podDisruptionBudget.minAvailable`

**Type:** `int`

**Default:** `1`

Minimum number of registry-server pods that must remain available.

Values for the Registry Server chart this chart wraps; every key under
`upstream` is passed to it. The Registry Server requires an external PostgreSQL
database: set `upstream.config.database.*`, or leave
`upstream.config.database.host` empty to inherit `global.postgres.host`; with
neither, the render fails. `upstream.config` is rendered into a ConfigMap, so
never put the database password in it. Pass the password through
`upstream.extraEnv` with a `secretKeyRef` instead. AWS RDS IAM authentication
does not inherit `global.postgres.dynamicAuth`; set
`upstream.config.database.dynamicAuth.awsRdsIam.region` here.

**Type:** `object`

      weight: 50

</details>

Preferred spread of registry-server replicas across nodes and zones. Your own
`upstream.affinity` merges with this; set `podAntiAffinity: null` to drop it.
The selectors match the Registry Server pods' `app.kubernetes.io/name: upstream`
label. If you set `upstream.nameOverride`, change `app.kubernetes.io/name` in
these selectors to the same value, or the render fails.

### `upstream.fullnameOverride`

**Type:** `string`

**Default:** `"registry-api"`

Override the upstream Registry Server resource names. The default gives the
Deployment and Service the name `registry-api`.

### `upstream.imagePullSecrets`

**Type:** `list`

**Default:** `[{"name":"enterprise-pull-secret"}]`

Image pull Secrets for the Registry Server pod. The default authenticates to the
Replicated image proxy with `enterprise-pull-secret`.

### `networkPolicy.enabled`

**Type:** `bool`

**Default:** `false`

Enable a NetworkPolicy for the Registry Server pod. The render fails while
`upstream.nameOverride` is set, because the policy selects pods by the default
name label.

### `networkPolicy.allowExternalEgress`

**Type:** `bool`

**Default:** `true`

Allow all egress. NetworkPolicies are additive, so `true` grants allow-all
egress and overrides a cluster default-deny. Set `false` and populate `egress`
to lock the pod down. With the policy enabled, the render fails when this is
`true` and `egress` is non-empty, because the list would be ignored.

### `networkPolicy.egress`

**Type:** `list`

**Default:** `[]`

Egress rules (NetworkPolicyEgressRule shape) used when `allowExternalEgress` is
`false`. Must cover DNS, PostgreSQL, and every sync source; a missing one fails
silently at run time. With the policy enabled, the render fails when this is
empty and `allowExternalEgress` is `false`, because the pod would have no egress
at all.
