Configure the ToolHive operator chart with these Helm values.

This reference lists values declared in the chart's default `values.yaml`.

Chart: `toolhive-operator`. Chart version: `0.24.0`. Generated from the platform
source at `v0.24.0`.

## Values

### `ha`

**Type:** `object`

**Default:** `{"podDisruptionBudget":{"minAvailable":1}}`

High availability for the operator. Set the replica count with
`upstream.operator.replicaCount` (or `autoscaling.minReplicas`); a
PodDisruptionBudget renders only above one replica. Extra replicas are
leader-election hot standbys.

### `ha.podDisruptionBudget.minAvailable`

**Type:** `int`

**Default:** `1`

Minimum number of operator pods that must remain available.

### `upstream.operator.affinity`

**Type:** `object`

<details>
<summary>Default value</summary>

```yaml
podAntiAffinity:
  preferredDuringSchedulingIgnoredDuringExecution:
    - podAffinityTerm:
        labelSelector:
          matchLabels:
            app.kubernetes.io/name: upstream
            app.kubernetes.io/part-of: upstream
        topologyKey: kubernetes.io/hostname
      weight: 100
    - podAffinityTerm:
        labelSelector:
          matchLabels:
            app.kubernetes.io/name: upstream
            app.kubernetes.io/part-of: upstream
        topologyKey: topology.kubernetes.io/zone
      weight: 50
```

</details>

Preferred spread of operator replicas across nodes and zones. Your own
`upstream.operator.affinity` merges with this; set `podAntiAffinity: null` to
drop it. Selector labels must match the upstream pods (`upstream` alias name;
part-of excludes registry-server pods, which share it).

**Type:** `bool`

### `upstream.operator.imagePullSecrets`
