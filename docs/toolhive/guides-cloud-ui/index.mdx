---
title: Open source Cloud UI is no longer supported
description:
  Open source ToolHive Cloud UI has been retired. Use the Registry Server,
  ToolHive UI, CLI, or Enterprise Cloud UI instead.
---

The open source ToolHive Cloud UI is no longer supported. The
[toolhive-cloud-ui repository on GitHub](https://github.com/stacklok/toolhive-cloud-ui)
is archived and will not receive updates.

## What to use instead

- **[Registry Server](../guides-registry/index.mdx)** - deploy and manage your
  MCP server catalog with the Registry Server API
- **[ToolHive UI](../guides-ui/index.mdx)** or
  **[ToolHive CLI](../guides-cli/index.mdx)** - browse and install MCP servers
  from the built-in catalog on your machine
- **[Enterprise Cloud UI](../../platform/enterprise-cloud-ui/index.mdx)** -
  Stacklok Enterprise web console for browsing and managing the MCP server
  catalog
