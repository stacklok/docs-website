---
title: ToolHive Cloud UI [retired]
sidebar_label: Cloud UI [retired]
description:
  The ToolHive Cloud UI is retired. Use the ToolHive UI or CLI to connect to a
  Registry Server instead.
---

The open source ToolHive Cloud UI is no longer supported. The
[toolhive-cloud-ui repository on GitHub](https://github.com/stacklok/toolhive-cloud-ui)
is archived and will not receive updates.

You can still run a [Registry Server](../guides-registry/index.mdx) to host your
MCP server catalog. Instead of browsing it through a separate web app, connect
the ToolHive UI or CLI to it directly:

- **ToolHive UI** - open **Settings** > **Registry** and select **Registry
  Server API** to point the desktop app at your Registry Server endpoint. See
  [registry settings](../guides-ui/registry.mdx#registry-settings) for details.
- **ToolHive CLI** - run `thv config set-registry <URL>` to point the CLI at
  your Registry Server. See
  [use a custom registry](../guides-cli/registry.mdx#use-a-custom-registry) for
  details.

If you don't have a Registry Server yet, see the
[Registry Server introduction](../guides-registry/index.mdx) to get started, or
the [custom registry tutorial](../tutorials/custom-registry.mdx) for a full
walkthrough.

Stacklok Enterprise customers can also use the
**[Enterprise Cloud UI](../../platform/enterprise-cloud-ui/index.mdx)**, a web
console for browsing and managing the MCP server catalog.
