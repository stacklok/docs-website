Virtual MCP Server (vMCP) combines tools from multiple MCP servers behind one
client connection. For the architecture and deployment trade-offs, see
[Understanding Virtual MCP Server](../concepts/vmcp.mdx).

## Choose your setup

| Your task                                             | Start here                                          |
| ----------------------------------------------------- | --------------------------------------------------- |
| Combine servers on your workstation without a cluster | [Run vMCP locally with the CLI](./local-cli.mdx)    |
| Deploy your first aggregated endpoint on Kubernetes   | [Kubernetes quickstart](./quickstart.mdx)           |
| Add backends or adapt a running Kubernetes deployment | [Configure vMCP on Kubernetes](./configuration.mdx) |
