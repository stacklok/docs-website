## Values

### `crds`

**Type:** `object`

**Default:** `{"install":true,"keep":true}`

Custom resource definition (CRD) installation and retention settings.

### `crds.keep`

**Type:** `bool`

**Default:** `true`

Add the `helm.sh/resource-policy: keep` annotation to each CRD so Helm retains
it when you uninstall the release.

### `crds.install`

**Type:** `bool`

**Default:** `true`

Include the chart's CRDs in the Helm release for installation and upgrades.
