## Values

### `crds`

**Type:** `object`

**Default:** `{"install":true,"keep":true}`

CRD installation configuration

### `crds.keep`

**Type:** `bool`

**Default:** `true`

Whether to add the "helm.sh/resource-policy: keep" annotation to CRDs When true,
CRDs will not be deleted when the Helm release is uninstalled

### `crds.install`

**Type:** `bool`

**Default:** `true`

Whether to install the CRDs in this chart
