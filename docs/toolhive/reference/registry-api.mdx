The Registry Server API provides server discovery and skill management
endpoints. See [Deploy with Helm](../guides-registry/deploy-helm.mdx) for
deployment and connection instructions.

On an endpoint page, select **Edit** under **Base URL** in the request panel.
Replace **registryUrl** with your deployment's URL, including any ingress path
prefix. For a local connection on port 8080, select `http://localhost:8080` from
the server list.

[Browse the API endpoints](registry-api-endpoints/toolhive-registry-api.info.mdx).
