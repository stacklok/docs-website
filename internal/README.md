# Website maintenance

Use this directory for instructions on operating and maintaining the docs
website. These files live outside the published documentation and are read
directly in the repository. The repository is public, so keep credentials and
other private information in the appropriate secret storage.

## Topics

- [Deploy and review the website](./deployment/README.md): Vercel builds,
  preview review, pull request checks, and production verification.
- [Maintain release documentation](./releases/README.md): Generated references,
  AI-assisted release updates, and incoming Enterprise Platform references.
- [Manage website search](./search/README.md): Algolia DocSearch and Ask AI
  indexes, crawler configuration, and validation.

Add a topic when there is a maintenance workflow to document. Keep its
instructions and supporting configuration together, and link it from this page.

For development commands and contribution guidance, see the
[repository README](../README.md).
